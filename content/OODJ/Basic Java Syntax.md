### Output Statement
``` JAVA
System.out.print(); //prints output and stays on the same line
System.out.println(); //prints output and moves to the next line
```
### Main Method
- `main` is the starting point of the program
- `String[] args` stores **command-line** arguments as text values
``` JAVA
public class Demo {
	public static void main(String[] args) {
		System.out.println("Hello Java!");
	}
}
```
