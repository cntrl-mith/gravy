## Definition of Open Source
Open source software is software with **source code** that anyone can use, study, modify and share. The source code is copyrighted when created, and only becomes open source when the holder provides it under license.

Open source software can still be provided for **commercial use**. In fact, it's a critical part of many organisation's commercial operations. While anyone can *sell* open source code, open source licensing generally allows customers to redistribute source code, as seen in [[#Types of Open Source Licenses]].
## Types of Open Source Licenses

| Feature          | Copyright                                           | Copyleft                                                              |
| ---------------- | --------------------------------------------------- | --------------------------------------------------------------------- |
| Goal             | restrict use to protect the author's right          | preserve freedom for users and developers                             |
| Usage            | needs permission or license to share/copy           | freely usable, modifiable, shareable                                  |
| Derivative Works | usually restricted                                  | allowed, but must keep same license                                   |
| Control          | creator controls how it's used                      | users retain freedom, creator ensures openness                        |
| TLDR             | You can't use or change this without my permission. | You can use and change this, but you must share it freely like I did. |
| Examples         | Microsoft Windows, Adobe Photoshop                  | Linux, LibreOffice                       
## Who Develops Open Source?
Open source development today is **overwhelmingly professional**. Instead of a body of volunteers, most open source devs are working for organisations that ==pay them to participate with open source projects== to construct contributions that the organisation needs.

Of course, volunteers and academics still play a vital role. The combination of formal and informal development leads to a productive environment.
