- **def:** Command line interface that allows users to interact with the operating system through commands.
- Accepts **human-readable commands**, converting them for the [[Kernel]] to understand.
- Default shell is usually set during the account creation process. It can be changed with the `chsh` command.
- common shells:
	- **Bash**
	  Most widely-used shell, default in Linux systems.
	- **Zsh**
	  Popular shell with features like command-line history, tab completion, and spell-checking.
	- **Fish**
	  Friendly Interactive Shell, newer and designed to be easier than bash. More user-friendly syntax and tab completion.
	- **Csh**
	  C Shell, based on the C programming language.
	- **Sh** 
	  The original shell in Unix systems. Simpler than bash but lacking in features.
	- **Powershell** 
	  dogshit microsoft shell for Windows
